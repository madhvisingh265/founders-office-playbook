# Interview Kit

A structured interview process I run for early-stage startup hiring. The goal is to make every candidate's interview **comparable**: same questions per stage, same 1–4 rubric, and written evidence before any hire/no-hire call.

## Process
| Stage | Owner | Length | Purpose |
|---|---|---|---|
| 1. Profile screen | Me | async | Hard filters (experience, degree, availability) + fit score → [`../candidate-screening`](../candidate-screening) |
| 2. **First-round interview** | **Me** | 30–40 min | Motivation, role fundamentals, communication, startup fit |
| 3. Role deep-dive / case | Hiring manager | 45–60 min | Technical or functional depth |
| 4. Founder round | Founder | 30–45 min | Culture, ownership, final call |
| 5. Debrief | Panel | 15 min | Scorecards compared **before** discussion, to avoid groupthink |

## Rules I follow
1. **Same core questions for every candidate in a role.** Follow-ups can differ; the core set can't.
2. **Score straight after the call**, against the rubric, with evidence in the candidate's own words.
3. **No "gut feel" scores.** Each score needs a reason written next to it.
4. **Score each competency on its own.** One impressive answer shouldn't raise the other scores (the halo effect).
5. Candidates get time for their own questions, and an answer within 48 hours either way.

## Rubric (used on every scorecard)
| Score | Meaning |
|---|---|
| 4 – Strong | Specific, first-hand examples with measurable outcomes; goes beyond the question |
| 3 – Meets | Clear relevant example; reasonable depth |
| 2 – Partial | Generic or second-hand answers; gaps on follow-up |
| 1 – Concern | No relevant example, or a red flag |

**Recommendation:** Strong yes (avg ≥ 3.5, no 1s) · Yes (avg ≥ 3.0, no 1s) · No (avg < 3.0 or any 1 in a must-have)
