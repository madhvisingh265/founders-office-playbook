# Daily Commit (sent to the founder every morning)

A short message at the start of the day committing to **outcomes** (not activities) that will be done by **7:30 PM**. At EOD, each line gets ✅ / 🟡 (partial, with reason) / ❌ (blocked, with what's needed).

## Template
**Good morning Sir, today's commits (by 7:30 PM):**
1. [Outcome] → [what "done" looks like]
2. [Outcome] → [what "done" looks like]
3. [Outcome] → [what "done" looks like]

**Need from you:** [decision / access / review], or "nothing today"

## EOD update
1. ✅ / 🟡 / ❌ [one line + link]
2. …
**Carry-over to tomorrow:** …

## Why outcomes, not activities
| ❌ Activity | ✅ Outcome |
|---|---|
| "Work on candidate sourcing" | "15 shortlisted Platform Engineer profiles in the tracker, scored" |
| "Research competitors" | "Competitor comparison doc v1 shared, covering 8 companies" |
| "Interviews" | "4 first-round interviews done; scorecards and recommendations in the tracker" |
